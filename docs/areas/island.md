### Island pages (PL6) and the page API


The opened island is page-first (BrimDeck-like, about 600 px wide on a monitor, a fixed height you can resize). **It fits the screen** (`core/islandFit.ts`, tested): Settings → Desktop island → Size → Quick pick is **Auto (fits your screen)** by default; the desktop reads the island's screen work area in logical px (scaling already applied) and a laptop (narrower than 1400 or lower than 760) gets **Compact** (panel 460–500 px, at most ~70 % of the screen's height, pages scroll inside), a normal monitor Normal (600 px), a 2400+ wide one Normal a little larger. Compact is a real density layer, not just smaller text: the `--dw-*` tokens in `island-fit.css` (type scale, spacing, card padding, rings, chips, buttons, the Now / Next card, the top bar), set by the `dens-compact` class. Compact / Normal / Large, the Panel width slider or a panel resized by its corner win over Auto; the panel never goes past the screen's bottom. A move to another screen or a scaling change re-sends the size (`island:prefs` carries `density`, `scale`, `panelWidth`, `panelMaxH`). Old island.json files with the old default "Normal" move to Auto once (`sizeV`). Layout: a slim top bar (Ben's avatar with a mood dot, the page tabs with a sliding indicator, search `/`, quiet, pin, open the app, close) and one page with the rest of the height. Swipe or drag sideways (the page follows the pointer, flicks carry on, the ends give like a rubber band), scroll sideways (or Shift + wheel; a plain wheel over the tabs), `1`–`9` jump to a page, Ctrl+← / Ctrl+→ or `[` `]` step. Pages slide with a little depth (Web Animations, transform and opacity only). The Day page starts with a hero (greeting, date, today's numbers counting up), the power row (four one-tap actions you pick with ✎: focus, water, quick note, a favourite automation, reps, music, Ben, quiet, add task; kept in `ls.islandPower`), then the morning card and your sections. The command bar lives in the `/` palette over the whole island (`islandWow.tsx`, entries in `core/islandPalette.ts`): any letter typed while the island is open goes into it; it keeps the command bar's own suggestions first (so Enter still logs `water 500` or asks Ben), then pages, quick logs, automations, music stations and island steps. Esc closes the palette first, then the island. Sounds go through `islandSounds.ts` (`play('open' | 'close' | 'page' | 'tap' | 'done' | 'error')`). Only the page you see is mounted, so nothing on the others runs or animates. Pages can open by the time of day or the island profile (synced setting, see Widgets). Pure logic: `src/core/widgets/pages.ts`; the pager and the API: `src/renderer/src/widgets/islandPages.tsx`.

To add a page (another builder, e.g. the Music tab), call once at import time:

```tsx
import { registerIslandPage } from './widgets/islandPages'
registerIslandPage({ id: 'music', title: 'Music', icon: '🎵', render: (ctx) => <MyMusicPage snap={ctx.snap} tap={ctx.tap} /> })
```

`id` is lower-case letters, digits or `-`; registering the same id again replaces the page (the built-in `music` page is a placeholder for exactly that). `ctx` = `{ snap, tap, now, day }` (`snap`: the island snapshot; `tap(action)`: send an island action; `day`: the Day page's own content). Optional `order` places a new page before you reorder (Day 0, Music 10, others 50). It returns a function that removes the page.

**System and AI usage pages (desktop only, `src/renderer/src/sysmon/`).** System: CPU per core (os.cpus deltas), GPU, memory, network with a small line, the 5 busiest apps (Close → `pcClose` action → the usual Allow / Deny card, then `taskkill` without /F; never Windows parts or this app: `SYSTEM_PROCS` in `core/sysmon.ts`), drives, temperatures and power only when Windows or LibreHardwareMonitor reports them, battery. The desktop (`src/desktop/sysmon/`, IPC `sysmon`) runs one PowerShell loop only while the page asks (stops after 5 s without a question). AI usage (off by default): Claude Code (`~/.claude/projects/**/*.jsonl`) and Codex (`~/.codex/sessions`) read locally, numbers only, 5-hour blocks like ccusage (`core/aiUsage.ts`, prices in `core/usagePrices.ts`), and Ben's month vs budget from `/api/ai {op:'usage'}`. Optional rings and CPU/RAM on the pill, 70 % / 90 % notices once per window. Settings → Desktop island → System and AI usage (file `sysmon.json` on that PC).

### Widgets, script tiles and the island look (PL1–PL11, LF1–LF2)

- **Widgets** (`widgets/` in the repo, `src/core/widgets/`, `src/renderer/src/widgets/`): one `widget.js` + `manifest.json` (+ `screenshot.png`) per widget, compiled into the app (Vite glob; nothing downloaded at run time). Each runs in an iframe `sandbox="allow-scripts"` only (opaque origin) loading `/widgets/frame.html` (`src/renderer/public/widgets/`: its own CSP, `connect-src 'none'`), gets its code over `postMessage` only after the island checked its sha256 against the hash pinned at install (`registry.ts loadCode`), and talks over a private MessagePort (`bridge.ts`: typed messages, `checkCall` on every call: permission, host allowlist, rate). Permissions (asked once at install, revocable in Settings → Widgets): `read` (the read-only data contract `widgetData`, built from the island snapshot: plan, focus, points, weather, next event, counts; never Ben's messages or task texts), `network` (listed https hosts, made by the desktop main process `src/desktop/widgetNet.ts` after the app window checks again), `add` (task / note, the island asks each time, `ConfirmCard`), `sound`. `vercel.json` has its own header block for `/widgets/*` (framable by the app only); Electron's permission handler gives `/widgets/` nothing. Gallery: `widgets/gallery.json`; after changing a widget run `node scripts/widget-hashes.mjs --write` (a test checks hashes, manifests and screenshots). How to submit one: `widgets/README.md`. `.gitattributes` keeps `widgets/**` LF so hashes match on Windows.

- **Speed budget (PL11)**: `budget.ts`. The island pings each widget every 3 s; late or missing answers and long tasks add strikes; 3 in a minute (or one freeze over 2.5 s) stop the widget and show "slowed down" with Try again. Data goes at the manifest's refresh rate (≥ 15 s), never while hidden; only the visible page is mounted.

- **Script tiles (PL5)**: `scripts.ts`, `scriptRun.ts`, `scriptRunner.ts`. Short JS ("show X when Y") run in a fresh blob Web Worker each time, locked down before the code runs (no fetch/XHR/WebSocket/BroadcastChannel/storage/workers; big buffers, arrays and strings capped), ended after 250 ms (+5 s while the host does a fetch). API: `life.now/hour/minute/weekday/today`, `show(text, icon)`, `notify(text)` (an island peek, at most every 10 min), `addTask(text)` (you confirm), `await fetch(url)` (only hosts you listed). Three timeouts in a minute pause it. Tested with real Node workers.

- **Synced setting `island_widgets`** (`settings.ts`): installed widgets (hash, grants, page, config), pages, scripts, the island look, and the synced layout (PL8: pill order and island look follow you to every PC by a three-way merge in `widgetsFeed.ts syncLayout`; screen positions stay per PC). The app window puts it in the snapshot (`snap.widgets`) and answers `{kind:'widget'}` island actions (`widgetAct`, checked again).

- **Rain and daylight on the pill (LF1/LF2)**: `weatherPill.ts`. From the weather plugin's saved data: pill items "Rain at 17:00" and "Sunset 16:40 · 2 h of light left" (pill items `rain`, `sun`), a peek 30 min before rain, and one daylight nudge on short days.

- **The island look** (`islandLook.tsx/.css`, Settings → Widgets → Island look): shapes Notch (flush with the top edge, round bottom corners; the default for new users, existing set-ups keep the Capsule), Capsule (the floating pill) and Thin bar (also by itself while a window is maximized on the island's screen: the desktop watcher reports `max=`). The thin bar is the **Indicator** (`IslandIndicator`): one small capsule flush with the top edge, centred on that screen (the page sends `islandBar(on)`, the desktop places the window with `barSpot` in `islandWin.ts`). A timer fills the capsule itself (amber in the last 5 minutes, faint for the current block), music adds a 3-bar equalizer, captions a red dot, an alert one accent pulse; no bottom line, outline, dots or bubbles beside it. Hover grows it into the pill, click opens. The smoke test checks it is exactly one visible bar, Open on hover, a pill clock (Simple, Seven-segment, Serif, your colour; redraws once a minute) and eight themes (Dark, Light, One Dark Pro, GitHub Dark, GitHub Light, Dracula, Night Owl, Cyberpunk). The page carousel slides the old page out and the new one in (260 ms, transform/opacity). **Clock time zones** (`core/worldClock.ts`, tested; `ClockZones.tsx` in Settings): up to 5 other IANA zones with optional short labels in the synced look (`zones`, `zoneBack`; `cleanLook` drops zones Intl doesn't know; empty = only your time). A tap on the pill's clock (or T on the focused pill) shows the next zone (local → zone 1 → … → local) without opening the panel (its own `data-tap`, double-click stopped), with a tinted label and a ±1 day marker; it goes back to your time after 30 s unless switched off; resting the mouse on it lists every zone; the panel shows one time per zone. Formatters are cached; the clock still redraws once a minute.

- **The resting island** (`core/islandRest.ts`, tested; drawn in `DesktopIsland.tsx`, styled in `island-rest.css`): the closed pill or notch shows one main thing and at most one small extra, by priority: a running timer, music playing, an event within 15 min, captions, something waiting (Ben's new message or a reminder: the red dot, with a tooltip that says which), the hour before bed. With nothing live it is calm: Settings → Widgets → Island look → "When nothing is happening, show" Next event (the default: what's on now or the next event today, else the time) / Time / Healthy day (the ring, only when there is something to show) / Nothing (`look.rest`). No water, movement ring, usage rings, page dots, bottom line or outline fill at rest: the grip, a hint line, the switch dots, CPU / usage and the side bubbles show on hover; the outline fill and the progress line only in the peek. The notch hangs flush from the top with concave shoulders (`.di-ears`) and a fixed height (30 px, 28 in Compact); it breathes only in Full motion while something live shows. The smoke test checks ≤ 2 items, no empty rings or placeholders and no stray lines.

- **How the island behaves: Calm / Balanced / Lively** (`core/islandCalm.ts`, tested; Settings → Desktop & island, top). **Calm is the default** (also for set-ups saved before it: no saved mode means Calm): at rest only a faint 48×3 line at its spot ("Show a small line") or nothing ("Show nothing"); clicks pass through everywhere, the line too. Resting the mouse in the zone around it (its resting width + 8 px; tiny over a maximized app, whose tabs and window buttons sit there) for 200 ms (400 ms over a maximized app) slides the pill out; staying on the pill 900 ms opens the panel (not while on a dot); away, it hides 600 ms later. New things peek as one slim line for `peekSec` (mouse on it → its card), only for the kinds on in "Peek for" (Ben, your reminders, water, move breaks, eye breaks, timer ending, meeting starting, bedtime; alive moments off), then wait as a coloured dot on the line and in the pill (water blue, move green, reminders/timers/meetings amber, Ben lime; a tap opens its card). The move break, the water card and the eye break are the exception: the real card with its own sound, see "Move breaks and water you can't miss" and "Body reminders come with sound and open as a card". The mode only ever turns a peek into a dot (`modeGate` on top of `alertGate`), so quiet hours, calls, focus, the gap and the healthy-day caps still apply. Balanced: the pill always there, only timers, your reminders, meetings and bedtime drop down. Lively: as before. Neither Calm nor Balanced opens the panel by itself before a meeting (it peeks). While hidden: no animation, rings paused, no lean polling on the desktop (the page sends `calm: true` with its click area). An older desktop that doesn't send a mode keeps Lively. Smoke step "Desktop island Calm".

### Ben on your PC: the live coach


Settings → Ben on this PC → "Let Ben see what I'm doing" (off by default; also a one-time card on the island) turns on the app in front, the Smart island, away time and today's totals on this PC (titles stay their own switch; off turns the app sensor and the Smart island off again). Then the island reacts to what you really do, from the title-free activity stream: praise after 25 / 50 / 90 min of coding, study, CTF or writing in a row (a look elsewhere under 90 s doesn't break it) and when the day's real work reaches your goal; "Back to <block>?" after 10+ min of video, games or social during a block, a focus timer or your work hours (Back to it / 5 more min / I'm on a break); a break card after ~50–60 min at the PC (💧 Water, 💪 10 push-ups, 🧍 Stretched, ⏰ 15 min: each logs only on your tap, through the usual water and move-break paths); the bedtime guard from 30 min before your bedtime (My life), firmer after it and direct when gaming late; good morning on the first use after your wake time; welcome back after 15+ min away; one evening recap. Logic: `src/core/pcCoach.ts` (pure, `pcCoach.test.ts`); the app window: `src/renderer/src/pcCoachFeed.ts`, called from the island build in `IslandFeed.tsx` (no new timers; today's totals at most every 3 min). How hard Ben pushes sets the gap (15/20/25 min), the daily cap and the thresholds; bedtime and drift may come sooner; nothing in meetings; breaks and bedtime go through the healthy-day governor. "Less of this" once makes a kind rarer, twice turns it off (back on in the same Settings page). Sounds: "Ben cheers your work" and "Ben calls you back to work" in Settings → Sound; Calm peeks them under "Peek for → Ben on your PC". Ben's evening review still gets only the totals, and only with "Share totals with Ben".

### Move breaks and water you can't miss (Calm too)

The owner sat an hour at the PC (Sunday, v1.4.1386, default settings) and saw no move or water reminder, only a thin green line. Cause (reproduced in `core/islandOwnerHour.test.ts`): the move break fired, but (1) its first 10 minutes were a dot only (`escalation`), (2) Calm turned the peek at 60 min into a 5-second slim line and then a 5 px green dot on the faint line, and (3) while that move dot waited, the water card below it in the chain could never come. No setting or app version was at fault.

- **Body cards are real cards.** `isBodyCard` (`core/islandCalm.ts`): the real move break (`move:…`, also the one held back by a call, and the screen-time break `coach:break:…`) and the water card (`water:…`). In Calm `presentAs` draws them as the full card (the exercise picker and −/+ count, +250 ml), not the slim line; Balanced lets them drop down too (never quieter than Calm). They stay `BODY_CARD_MS` (3 min) or until answered (the mouse on it keeps it), then wait as a dot. Posture, tidy, breathing, "Moved?", eye breaks and everything else keep Calm's slim line or dot. "Peek for → Move breaks / Water" off still makes them a dot.
- **No dot first.** `escalation` starts at a peek when the break is due (50 min of active time by default), a sound 25 min later, Ben's firmer line at 90.
- **No card twice.** `firstSight`: a card that comes back after another card was shown (same id) waits as its dot; the next step of the same sitting is new.
- **One doesn't hide the other.** In `dayNudge`, a body card nobody answered (a dot, or up for 3 min) lets the other body card come first.
- **The line says what it is.** A waiting move or water card shows a few words under the line ("🏃 Move break waiting · point here"), and until you first bring the island out with the mouse while one waits, "This line is your island. Rest the mouse on it to open it." (`ls.calmLineHint`). Clicks still pass through.
- **Why no reminder?** The Day page shows one small line (`whyNoReminder` from `nudgeWhy`, snapshot `nudgeWhy`) with the move break's and water's reason, e.g. "Move break: at the PC 12 min (break after 50)".
- **Where the line sits.** It stays where it was dropped (a drop in a screen's top zone snaps to top-left / centre / right; right of 75 % of the width is top-right). Tray → "Reset position (top centre)" puts it back. At rest it never takes clicks, so it can't block tabs or window buttons under it.
- Protections unchanged: calls, focus, classes, quiet hours, bedtime − 60, after bed, the 30-min gap, at most 3 different cards an hour (the governor), the daily caps and learning. Points unchanged (paid only on a confirmed log, undone with it). Tests: `core/islandOwnerHour.test.ts`; smoke step "Desktop island reminders" (cards made by the real chain, bundled).

### Body reminders come with sound and open as a card

The owner: eye care and water reminders came with no real sound and never opened properly. Causes: (1) the island window had no autoplay permission, so Chromium kept its audio asleep until a click on the island, and in Calm every click passes through, so reminder sounds almost never played; (2) eye breaks were off twice by default (the generator switch `ls.eyeBreaks` and "Peek for → Eye breaks"), and even when on they were Calm's slim line; (3) the kit's reminder notes are soft (gain about 0.1 × the island's 0.7 volume).

- **Sound that plays.** The island window has `autoplayPolicy: 'no-user-gesture-required'` (`src/desktop/island.ts`), so its sounds play without a click first. Needs the app update (desktop side).
- **One plan per reminder** (`core/islandReminderSound.ts`, tested with a pinned clock): `reminderPlan` gives `{expand, sound}` for water (`water:…`), the eye break (`eyes:…`), the move break (`move:…`) and the screen break (`coach:break:…`). An allowed one (it passed `alertGate` + `modeGate`) opens as the full card (`presentAs` = card) in Calm, Balanced and Lively and plays its own sound once (`rangIds` in `DesktopIsland.tsx`: never again on a re-render or when it comes back). No sound when it waits as a dot, in a call, quiet / quiet hours, a focus timer, a class, after bed is logged (snapshot `hush` from `hushOf(govCtx)` in `IslandFeed.tsx`), when the system says audio is off (where the browser can tell), with the island's Sounds or that kind's 🔔 off (Desktop island → Reminders), or with its own switch off. Windows Focus assist / Do not disturb can't be read by the page; quiet hours cover that.
- **Distinct sounds** (Settings → Sound → "Which sound for what" can change each): water a drop, eye break the glass chime, move break the marimba climb, screen break a new calm bell (moment `screen`, sound `calmbell`, `remindScreen`). The eye countdown ends with a soft done chime (same switches).
- **Settings → Sound → Island reminders:** a switch and a ▶ test per kind and one Reminder volume (default 80 %, `uiPrefs.sounds.reminders`). It works even with the app's main Sounds switch off. The volume lifts the soft notes (`reminderGain`, 80 % ≈ 2× the old island reminder; the kit's limiter keeps it clean). The old in-card sound at the move break's "sound" step is gone (the card's first sound replaces it).
- **Eye breaks on by default.** `EYE_BREAKS_DEFAULT`: nothing saved in `ls.eyeBreaks` means on; a saved off stays off. "Peek for → Eye breaks" defaults on; a saved `false` from before `PEEK_FOR_V` 2 is read as on once (it could not be told from the old default), a choice saved from v2 on is kept (`cleanPeekFor`, `peekForV` in the island prefs). The eye card is a body card (stays up to 3 min, then a dot; "👁️ Eye break waiting" under the line), with the real 20 s countdown on the pill.
- **Big buttons:** body cards (`.di-peek.body-card`) use 36 px buttons and larger −/+.
- Protections unchanged (30-min gap, 3 an hour, daily caps, learning, quiet hours, calls, focus, classes, bedtime − 60, after bed). Points unchanged. Smoke step "Desktop island reminders" checks the move, water and eye cards expand (bigger than the line) and that each rings exactly once (the `life-island-reminder-sound` event).

### The alive island and game time
