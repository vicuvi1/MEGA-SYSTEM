# Sport Track design (approved by the owner, Nov 2026)

The approved design for Sport Track, as Design-canvas artboards (`*.dc.html`, one per screen).
They are the visual spec: match layout, hierarchy, sizes and copy; use real data in the app.

- `Main` = Dashboard · `Workout` · `Exercises` · `Progress` (with Path progress) · `BodyFood` (AI prompt + paste)
- `Growth` = "Am I really growing?" (verdict + 6 signs + lean-gain chart + photo check)
- `Swap` = tap a move → pick easier / harder with a real photo demo
- `Gear` = what you own; the plan only uses ticked equipment (sturdy table / desk too weak / no table)

Photos: `/_blob/<id>` urls in the files are canvas uploads of `src/renderer/public/apps/sport/photos/<move>-0|1.webp`
(Free Exercise DB, Unlicense). In the app use those local files; the demo cross-fades frame 0 and 1.
Numbers in the design are examples.
